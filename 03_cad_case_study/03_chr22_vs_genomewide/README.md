# 03 — chr22 pilot vs genome-wide PRS

This final comparison asks whether the earlier chromosome-22 pilot behaves like the complete autosomal PRS.

For the same 503 individuals:

- Pearson `r = 0.0973`
- Spearman `rho = 0.1215`
- linear-model `R² = 0.00948`

The weak relationship shows that a single-chromosome pilot is useful for validating the workflow, but it cannot substitute for a genome-wide polygenic score.
