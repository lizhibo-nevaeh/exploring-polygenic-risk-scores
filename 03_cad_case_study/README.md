# Part 3 — Real-world CAD application

The final part moves from tutorial data to a real coronary artery disease GWAS.

1. **chr22 pilot:** validate the entire real-data workflow on one chromosome.
2. **genome-wide extension:** generalize the validated workflow to autosomes 1–22 and calculate genome-wide PRS in 503 1000 Genomes European-ancestry individuals.

The target panel is used for genotype scoring and population-level distribution checks. It is **not** a CAD phenotype-validation cohort.
