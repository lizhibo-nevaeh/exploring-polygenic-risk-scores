# 06 — LDpred2

This stage introduces Bayesian, LD-aware effect-size estimation.

Two tracks are preserved:

- exploratory scripts used while learning the mechanics;
- a cleaner run based on the official LDpred2 tutorial data.

The official tutorial run used 30 LDpred2-auto chains. The retained chain summaries show no missing posterior betas and stable estimates across chains. A compact top-15 table compares GWAS effects with LDpred2 posterior weights.
