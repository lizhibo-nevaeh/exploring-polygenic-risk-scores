# 03 — PRS-CS

PRS-CS introduces Bayesian regression with continuous shrinkage priors and an external LD reference.

This stage first used chromosome-22 tutorial data to compare:

- a fixed shrinkage parameter (`phi = 1e-2`);
- PRS-CS-auto, where the global shrinkage parameter is estimated from the data.

The retained files focus on the statistical comparison of GWAS effect sizes and PRS-CS posterior effect estimates.

Third-party PRS-CS source code is not redistributed in this repository.
