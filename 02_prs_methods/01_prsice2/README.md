# 01 — PRSice-2

PRSice-2 automates the clumping-and-thresholding strategy explored manually in Part 1.

The retained output from the tutorial dataset shows:

- N = 2,000;
- 1,000 cases and 1,000 controls;
- best P-value threshold = 0.4463;
- 36,759 SNPs in the best PRS;
- PRS R² = 0.0520;
- OR per SD = 1.509 (95% CI 1.375–1.656).

These are tutorial-data results used to understand C+T model selection, not results from the final CAD case study.
