# 03 — LD and clumping

**Question:** Why should correlated SNPs not all be counted as independent evidence?

The toy LD example contains SNPs with very different pairwise LD. PLINK clumping is used to retain representative signals while avoiding repeated counting of nearly identical genetic information.

This folder contains the actual toy genotype files, LD output, clumping result, and SNP lists used in the exercise.
