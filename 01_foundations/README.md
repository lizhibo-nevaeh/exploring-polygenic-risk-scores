# Part 1 — PRS foundations

This section uses deliberately small examples to make the mechanics visible before introducing large software packages.

1. **Toy PRS** — calculate a score as genotype dosage × effect size.
2. **Allele harmonization** — show that software can run successfully while the biological direction is wrong if the effect allele is misaligned.
3. **LD and clumping** — show why highly correlated SNPs should not be counted as independent evidence.
4. **Manual C+T** — combine clumping with GWAS P-value thresholds.

These are learning examples, not disease models.
